## The task

Small inconsistencies create large headaches: duplicate contacts, mixed date formats, missing sources, inconsistent capitalization, and status labels that mean the same thing in different ways.

- Duplicate rows

- Notes mixed into structured columns

<section class="sorbet-after" markdown="1">
### After

- Notes separated from core fields
- Consistent capitalization and spacing

## QA checklist

1. Preserve the original file before editing.
2. Standardize one column at a time.
3. Flag uncertain duplicates instead of deleting them automatically.
4. Keep a short change log for any rule that affects many rows.
5. Spot-check the final sheet for broken links, shifted columns, and missing values.
6. Return a clean file plus concise notes on anything that still needs a human decision.

## Handoff

A good spreadsheet handoff should be understandable without a meeting. Column names are clear, statuses are consistent, unresolved items are visible, and the next person can continue the work without reverse-engineering the cleanup.
